# Solfegio

A SwiftUI piano app for iOS with MIDI file support and real-time pitch detection.

## Features

- Multi-touch piano keyboard with low-latency audio
- MIDI file reading and writing via [swift-midi-file](https://github.com/orchetect/swift-midi-file)
- [Planed] Real-time pitch detection for vocal training (YIN algorithm)


## Requirements

- iOS 16.0+
- Xcode 15.0+
- Swift 5.9+
