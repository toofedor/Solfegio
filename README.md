# Solfegio

A SwiftUI piano app for iOS with MIDI file support and real-time pitch detection.

## Features

- Multi-touch piano keyboard with low-latency audio powered by SwiftUI (Low-latency touch control implemented with UIKit)
- MIDI file reading and writing via [swift-midi-file](https://github.com/orchetect/swift-midi-file)
- Sound library GeneralUser GS 1.472 by [S. Christian Collins](https://www.schristiancollins.com)
- [Planed] Real-time pitch detection for vocal training (YIN algorithm)


## Requirements

- iOS 16.0+
- Xcode 15.0+
- Swift 5.9+
